# 更新手册

本手册面向不关心技术细节的普通用户，覆盖安装、升级、迁移、备份和常见故障。
先交代三个基本事实，后面所有场景都建立在这之上：

1. 内阁是便携式软件：不写注册表、不用安装器，整个文件夹复制到哪都能用。
2. 你的全部数据（配对证书、设置、下棋记录）都在程序目录的 `appdata` 文件夹里，
   与程序文件 `cabinet.exe` 相互独立。
3. 升级 = 用新的 `cabinet.exe` 替换旧的。数据不动、手机不需要重新扫码。

## 情况 0：首次安装

1. 到 [发布页](https://github.com/Silva6c/cabinet/releases) 找最新的 **stable** 版本，
   下载 `Cabinet-Portable-日期-Full.zip`（新用户只需要这一个）。
2. 解压到任意目录（路径可以含中文），双击其中的 `cabinet.exe`。
3. 按包内《使用说明.txt》完成：防火墙允许 → 手机扫二维码配对。

---

## 情况 1：常规升级

先试软件内升级（推荐）：控制台「高级功能 → 检查更新」——查到新版后点
「下载并安装」，校验通过会自动换入并重启，不用手动覆盖文件。该通道依赖
GitHub 发布页可达；软件提示查不到新版时，按下面的手动步骤来。

1. 从托盘退出内阁。Windows 会锁定正在运行的程序文件，不退出就无法覆盖。
2. 下载新版的 `Cabinet-Update-日期.zip`，解压，把里面的 `cabinet.exe`
   复制到原目录，选择"替换目标中的文件"。
3. 重新启动。控制台窗口标题栏显示版本号，与发布页一致即升级完成，
   手机端会自动重连。

建议在覆盖前把旧 `cabinet.exe` 复制一份并改名（例如 `cabinet-旧版.exe`）
留在原目录：对新版不满意时改回文件名即可退回旧版，其他什么都不用动。

## 情况 2：手机端更新

- 电脑和手机都工作正常时，不更新没有任何影响；发布页说明中提到手机端
  有新功能或修复时再更新。
- 两端版本没有配对要求，先后随意。差别只在：需要两端配合的新功能
  （例如设备昵称），两端都更新到新版才能看到。
- 更新方法：下载 `cabinet_日期_编号_arm64.apk`（真机用 arm64；x86_64
  是给电脑上模拟器用的），在手机上直接安装覆盖。不需要卸载旧版，
  配对信息保留。

安装被拒绝时，通常是识别服务还在运行：从手机通知栏停止内阁服务再装。

---

## 情况 3：升级后异常的处理

按顺序尝试：

1. **重启程序。** 托盘退出后重新启动 `cabinet.exe`，多数异常到此解决。
2. **检查防火墙放行。** 升级后首次启动若 Windows 询问是否允许联网，选择允许；
   误点拒绝可在"Windows 安全中心 → 防火墙 → 允许应用通过防火墙"中补勾。
   注意防火墙规则绑定的是程序路径：把程序放到了新位置，需要重新放行。
3. **退回旧版。** 用留存的旧 `cabinet.exe` 覆盖回去即可，数据与新版建立过的
   库完全兼容，不需要清理。

以上无效时，把 `logs\cabinet.log` 提供给能够帮忙排查的人，该文件记录了
程序运行中的错误详情。

不要通过删除 `appdata\cert` 来"重置连接"：该文件夹是配对证书，删除后
所有已配对手机都要重新扫码。

## 情况 4：换机与重装

整个文件夹（连同 `appdata`）复制到新环境即可，无安装步骤。

- 带上 `appdata\cert`：手机无需重新扫码。
- 不带：手机重新扫一次码（约一分钟），其余数据不受影响。
- 新环境首次启动记得在防火墙中放行。

---

## 情况 5：引擎与棋谱库

内阁的分工：手机负责识别棋盘，电脑负责计算。电脑端有两样独立于程序的东西：

- **引擎（皮卡鱼）**：负责计算走法，安装包自带，通常不需要单独更新。
- **棋谱库（桔库）**：开局阶段的标准着法库，同样自带。

只有发布页说明中明确提到"引擎升级"或"棋库更新"时才需要处理：

- 引擎更新：下载附带的包，把其中 `appdata\library\` 下的文件按相同子路径
  复制进你自己的 `appdata\library\` 覆盖。
- 棋谱库更新：把新的 `.obk` 文件放进 `appdata\library\books\` 即可，
  程序自动加载，无需重启。

Update 包默认只含 `cabinet.exe`，不含引擎和棋库——这两样更新频率很低，
没有必要每次升级都重新下载。

---

## 情况 6：备份

`appdata` 文件夹就是全部数据，复制它即完成备份：

| 子目录 | 内容 |
|---|---|
| `cert` | 配对证书（决定手机是否需要重新扫码） |
| `data` | 下棋历史与建议记录 |
| `configs` | 用户设置 |
| `library` | 引擎与棋谱库 |
| `logs` | 日志（排障用，可不备份） |

升级前顺手复制一份到其他位置即可。

## 附录 A：下载文件对照

| 文件 | 用途 |
|---|---|
| `Cabinet-Portable-日期-Full.zip` | 首次安装（电脑，全量） |
| `Cabinet-Update-日期.zip` | 电脑常规升级（仅程序文件） |
| `cabinet_日期_编号_arm64.apk` | 手机更新 |
| `cabinet_日期_编号_x86_64.apk` | 电脑模拟器联调，普通用户不需要 |

- 文件名中的日期是制作日期。早期一批包的日期比发布日早一天（制作环境
  时区原因），属正常现象。
- "vc 数字"是版本编号，数字越大版本越新。

## 附录 B：常见问题

**杀毒软件报风险？**
误报。未购买代码签名证书的独立程序常被误判。确认从官方发布页下载后，
将程序目录加入杀软白名单。

**手机提示"指纹不匹配"？**
说明电脑端配对证书与手机记录的不一致，通常是 `appdata\cert` 被移动或
重建过。删除手机上的旧连接、重新扫码即可。

**能把文件夹挪到其他盘吗？**
可以，整个文件夹移动即可。挪动后需要在防火墙中对新路径重新放行。

**能同时开两个吗？**
不能，第二实例会弹窗提示并退出。

**Update 包解压后只有一个文件，正常吗？**
正常，常规升级包只包含程序文件，原因见情况 5。

**怎么查看当前版本？**
电脑看控制台窗口标题栏，手机在应用内设置页查看。
