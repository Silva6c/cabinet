内阁 cabinet —— 绿色便携版使用说明
================================================

一、首装与配对
  1. 将本文件夹整体解压到任意目录（路径可含中文，如 D:\工具\内阁）。
  2. 双击 cabinet.exe 启动。任务栏（可能在右下角溢出区 ^）出现托盘图标，
     同时弹出控制台窗口，窗口上有连接二维码。
  3. 首次运行若 Windows 防火墙弹窗，请点"允许访问"（专用与公用网络都勾上）。
     若误点了拒绝：到"Windows 安全中心 → 防火墙和网络保护 → 允许应用通过
     防火墙"里手动勾选 cabinet.exe。
  4. 手机端安装内阁 APK，打开后扫控制台窗口上的二维码完成配对，
     之后在手机上下发棋局即可收到电脑端引擎建议。

二、升级（只换 exe）
  用新版本 Update 包里的 cabinet.exe 覆盖本文件夹中的旧 cabinet.exe 即可。
  配置、证书、历史建议记录全部保留，手机无需重新扫码配对。
  （若升级包附带 appdata\library 文件夹，把其中文件按相同子路径复制进
  本文件夹的 appdata\library 下覆盖即可。）

三、搬机 / 备份
  整个文件夹拷走即完成备份/迁移——绿色软件，免安装、零注册表。
  若想免重新扫码配对，请把旧机器 appdata\cert\ 文件夹一并带走
  （证书是手机配对信任的根，一经生成不会自动重建）。

附注：所有数据（配置/证书/日志/引擎/棋库）都在 appdata\ 文件夹内。
卸载请连同 appdata\ 一起删除；日常备份也只需备份这个文件夹。

每个功能的详细用法见项目仓库 docs\用户说明书.md
（GitHub: github.com/Silva6c/cabinet）。
